# 改修前に戻す方法

改修前のコミット: `6d31b177d190149781925a5a9c979fa28890c42b`
保存用ブランチ: `backup/before-usability-2026-11-01`

このブランチは改修前の版を指します。削除したり、新しい変更を追加したりせず保管してください。

## 公開後に元へ戻す場合

GitHubで今回の改修をマージしたPull Requestを開き、Revertから取り消し用Pull Requestを作り、内容を確認してmainにマージします。Vercelのmain連携が継続していれば再デプロイされます。後続の変更と競合した場合は、履歴を強制的に巻き戻さず、その競合を解決してください。

旧版を別に取り出すには、GitHubのブランチ選択で保存用ブランチを選び、Code → Download ZIPを利用できます。

## 保存候補

保存キー `anagram_candidates` は維持し、元の語句と小文字結合設定を追加しました。旧形式も読み込めます。旧候補には元の語句の並び順が記録されていないため、保存済みの作成中・残り文字から補完したことを表示します。

候補の保存・削除を実行するまで既存ストレージを書き換えません。新形式にも旧版が読むphrase/remaining/cursorを残しているため、旧版でも候補の文字情報を読み込めます。ただし旧版で再保存した候補には追加情報が付かないことがあります。

ブラウザ内の保存データはGitでは復元できません。Vercelのプレビューと本番は別の保存領域です。プレビューで本番の候補が見えなくても、本番の候補が消えたわけではありません。
